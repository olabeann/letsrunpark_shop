# 말마프렌즈 온라인 스토어 견적 산정용 개발 전달서 v2.3

말마프렌즈 온라인 스토어
견적 산정용 개발 전달서

개발 범위와 산정 전제를 확인하는 문서

v2.3  |  2026년 9월 18일

기존 렛츠런플레이에 회원용 굿즈 스토어를 추가하고, 기존 관리자에 커머스 운영 메뉴를 확장한다. 개발사는 아래 기본 범위 12개 항목과 선택 범위 2개 항목을 구분하여 공수와 비용을 산정한다. 금액과 일정은 개발사의 검토 후 확정한다.

| 견적 구분 | 기본 범위 12개 항목 / 선택 범위 2개 항목 / 운영 실비 구분 |



## 이번 견적에서 제외하는 기능

예약권과 굿즈 혼합 결제, 상품 옵션, 할인·쿠폰, 부분 취소·환불, 분할 배송, 자동 반품, 택배 API, 자동 알림, 비회원 구매, 해외 배송, 후기·문의·찜, 송장 엑셀 업로드와 양식 다운로드.

예약관리시스템의 기존 업무 기능 변경 및 별도 관리자 신규 구축은 제외한다. 화면 디자인은 제공된 디자인 적용과 기존 관리자 수정 기준이며 신규 이미지 제작과 별도 디자인 시안 제작은 추가 산정한다.

## 산정에 적용할 동작 기준

한 주문에 여러 상품을 담고 한 번 결제하며 배송지는 한 곳으로 처리한다. 상품에는 옵션을 두지 않는다. 비로그인은 탐색만 허용하며 구매와 주문 조회는 기존 회원 인증을 사용한다.

취소는 주문 전체 단위로 PG 전액 취소와 재고 복원을 처리한다. 배송비 포함 여부와 허용 기한은 확정이 필요하다. 송장은 관리자가 직접 입력하고 배송조회는 외부 링크로 제공한다.

배송비 3,000원과 취소 24시간은 시연 기본값이다. 기본 견적은 주문당 정액 배송비와 단일 취소 기한을 전제로 하며 조건부 무료배송이나 지역별 배송비는 포함하지 않는다.

## 관리자 수정 기준

기존 관리자 안에 예약관리시스템과 커머스관리시스템 그룹을 둔다. 예약 그룹은 기존 5개 메뉴를 유지하고, 커머스 그룹에 굿즈 판매 현황과 온라인 스토어 운영을 배치한다.

표 제목과 내용의 열 가운데 정렬, 드롭다운 화살표 위치 조정, 표 아래 완료 문구 제거를 기본 화면 수정에 포함한다. 별도 관리자 구축으로 중복 산정하지 않는다.

출고는 송장 직접 입력 방식이다. CSV 내려받기는 유지하며 송장 엑셀 업로드는 제외한다. 상단 공통 택배사 선택과 주문별 예외 변경으로 단순화하는 UI는 제안 단계이므로 포함 여부를 명시한다.

상품 기본 설명 입력은 기본 범위에 포함한다. 서식·이미지·영상 편집 도구와 배송비·취소시간 설정 화면은 5쪽의 선택 범위로 별도 산정한다.

## 견적에 영향을 주는 확인 사항

| 확인 사항 | 기본 산정 전제 또는 추가 비용 기준 |
|---|---|
| 회원과 PG 재사용 | 기존 회원·PG를 활용하되 연결 작업은 포함. 기존 모듈 수정이나 신규 결제 계약이 필요하면 별도 표시 |
| 정책과 운영 규모 | 배송비·취소·관리자 예외·합포장·예상 상품수 및 주문량 확정. 복수 정책이나 대량 처리 요구는 추가 산정 |
| 자료와 인프라 | 고객사 상품 자료·이미지·안내 문구·디자인 제공. 기존 서버 용량 내 배포 전제. 추가 서버·저장 공간과 외부 서비스 이용료는 분리 |
| 장바구니와 기록 | 기기 간 장바구니 공유·자료 이관·이력 조회 화면·기록 보존 기간은 확정 전. 기본 포함 여부와 추가 공수를 명시 |



현재 화면은 업무 흐름 시연 자료다. 실제 인증·카드 승인·권한·서버 저장 연동이 완료된 것으로 산정하지 않는다. 시연 코드의 재사용 가능 범위는 개발사가 확인한다.
