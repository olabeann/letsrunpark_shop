# 렛츠런파크 굿즈 스토어 UX/UI 검토

검토일: 2026-09-18. 사용자 화면은 390px 모바일에서 메인·상품 상세·로그인 진입·주문서·주문 목록을 확인했다. 관리자 화면은 1280px에서 주문 목록·상품 편집·일괄 배송을 확인했다. 주문 상세와 기타 상태는 화면 및 코드를 함께 검토했다. 변경이나 배포는 하지 않았다.

## 판단

노란색 구매 버튼, 검정 가격, 회색 수량 영역으로 이어지는 현재 방향은 유지할 만하다. 개선의 중심은 색상 교체보다 정보 순서, 스크롤 길이, 터치 영역, 상태 안내다. 스트로크는 입력 경계와 꼭 필요한 표 구분에만 사용하고, 콘텐츠 구분은 여백·배경색·타이포그래피로 처리하는 방향을 권한다.

현재 사용자 화면은 좁은 화면에 맞춰 한 열로 바뀌지만, 모바일 구매 흐름을 충분히 고려한 구성은 아니다. 관리자 화면은 업무 구분은 명확하지만 글씨와 버튼이 작고, 편집 및 저장 동선이 길다.

## 권장 반응형 구성

- 사용자 화면 320–480px: 16–20px 좌우 여백, 상품 목록 기본 2열. 320px에서 이름·가격·터치 영역이 부족하면 1열 전환을 검토한다. 상품 상세는 이미지 → 상품명·가격 → 배송 안내 → 수량 → 상세 콘텐츠 순서와 하단 구매 영역으로 구성한다.
- 사용자 화면 481–767px: 콘텐츠 길이와 상품 수에 따라 2열 유지. 메인 배너는 모바일 비율을 유지한다.
- 사용자 화면 768–1023px: 상품 상세를 무조건 2열로 압축하지 말고 정보 영역의 실제 폭을 기준으로 전환한다. 긴 상품명과 이미지 비율을 확인한다.
- 사용자 화면 1024px 이상: 현재 이미지·구매 정보 2열 방향 유지. 구매 정보의 최대 폭과 이미지 크기를 조절한다.
- 관리자 화면: 데스크톱 업무 밀도 유지. 작은 화면에서는 필터 접기와 표 가로 스크롤을 명확하게 제공하며, 상품 편집·저장·닫기 행동은 항상 접근 가능하게 한다.

## 적용 순서

1. 수량·재고 제한, 품절 시 불필요한 수량·총액 제거.
2. 모바일 상품 상세 하단 구매 영역 및 터치 영역 확대.
3. 메인 배너 축소, 모바일 주문서 정보 순서 개선.
4. 관리자 고정 저장 영역, 변경 내용 보존, 표 가독성 개선.
5. 대표 이미지 입력과 전체 상품 미리보기, 푸터·상태 배지 정리.

## 검토 범위의 한계

390px 모바일과 1280px 관리자 화면의 관찰 결과 및 코드 확인에 근거한 검토다. 320px·태블릿·실제 iPhone/Android·키보드 노출·긴 에디터 콘텐츠·대량 주문은 추가 검증이 필요하다. 브라우저 도구가 모든 뷰포트 변경을 적용하지 않아 미확인 크기를 검증 완료로 간주하지 않았다.

로그인·주문·결제는 현재 브라우저 저장 기반 시연 구조다. 실제 외부 로그인·카드 결제·다른 기기 간 저장은 검증하지 않았다. 실제 구매 완료·주문 취소·일괄 발송은 수행하지 않았다.
