# 말마프렌즈 스토어 UX 점검

정책 개정 2026-10-07

## 사용자 화면

- 상품·주문 목록의 개수와 페이지 이동을 일관되게 표시합니다.
- 상품 수량과 구매 금액을 즉시 갱신합니다.
- 입력 오류는 해당 필드에 표시하고 기존 값을 유지합니다.
- 모바일 구매 버튼은 하단 안전영역과 본문 여백을 확보합니다.

## 관리자 화면

- 검색·필터 변경 시 1페이지로 이동합니다.
- 송장 입력 오류는 해당 주문 행에 표시합니다.
- 환불 금액과 고객 안내를 확정 전에 확인합니다.
- 정책 패널은 소제목으로 묶고 항목 이름을 강조합니다.
