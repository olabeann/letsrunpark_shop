## 파일 사용 기준

- 일반 검토·외부 전달에는 `.docx`와 `.pdf` 파일을 사용합니다.
- 내용 수정과 변경 이력 비교에는 `.md` 파일을 사용합니다.
- 기능 데이터 가공이나 시스템 연계에는 `기능목록.json`을 사용합니다.
- 이전 견적서와 과거 전달자료는 프로젝트 루트의 `_archive`에 보관되어 있으며 이 폴더에서는 제외했습니다.
