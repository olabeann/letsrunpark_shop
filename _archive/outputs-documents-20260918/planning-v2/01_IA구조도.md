# 말마프렌즈 온라인 스토어 IA 구조도

정책 개정 2026-10-07

## 사용자 이동

스토어 → 상품 목록 → 상품 상세 → 로그인 → 장바구니 또는 바로 구매 → 주문서 → 결제 → 주문 완료

주문 조회 → 주문 상세 → 취소 또는 반품 → 반품 운송장 → 결과 확인

| 화면 ID | 화면 | 접근 | 경로 | 연결 |
| --- | --- | --- | --- | --- |
| SCR-U-001 | 스토어 메인과 상품 목록 | 공개 | index.html / #products | 상품 상세 |
| SCR-U-002 | 상품 상세 | 공개 | #product/{id} | 장바구니 / 바로 구매 |
| SCR-U-003 | 로그인 팝업 | 구매 및 주문 조회 전 | loginModal | 기존 행동 복귀 |
| SCR-U-004 | 장바구니 패널 | 회원 | cartPanel | 주문서 |
| SCR-U-005 | 주문서와 필수 동의 | 회원 | #checkout | PG 결제 |
| SCR-U-006 | 주문 완료 | 주문 소유자 | #complete/{number} | 주문 조회 |
| SCR-U-007 | 본인 주문 목록 | 회원 | #orders | 주문 상세 |
| SCR-U-008 | 주문 상세와 취소 반품 | 주문 소유자 | #orders/{number} | 배송조회 / 반품 운송장 |
