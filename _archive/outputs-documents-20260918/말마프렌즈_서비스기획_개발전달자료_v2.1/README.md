# 말마프렌즈 온라인 스토어 개발 전달 자료 v2.1

작성일 2026-09-18. 기존 문서와 현재 시연 코드를 기준으로 다시 정리한 기획 개정안입니다. 운영 정책과 실제 연동은 확정 또는 검증되지 않았습니다.

1. [IA 구조도 Word](01_말마프렌즈_IA구조도_v2.1.docx) — 화면 구조, 사용자·관리자 IA, 화면 ID, 접근 조건, 현재 경로.
2. [기능명세서 Word](02_말마프렌즈_기능명세서_v2.1.docx) — FN-001~FN-026, 현재 구현, 목표 동작, 시작 조건, 검증·예외, TC 연결.
3. [개발 전달서 Word](03_말마프렌즈_개발전달서_v2.1.docx) — 서비스 소개, 정책·권한, 상태·복구, 데이터, 논리 API, DEC-001~DEC-015 결정 목록, TC-001~TC-033 검수.

편집용 원문은 [IA](01_IA구조도.md), [기능명세](02_기능명세서.md), [전달서](03_개발전달서.md)입니다. IA 원문에는 Mermaid 구조도를 포함했습니다. Word와 원문은 동일 생성 데이터에서 작성합니다.

구조도 이미지는 [사용자](01_사용자_IA.png), [관리자](02_관리자_IA.png)입니다. 기능별 구조화 데이터는 기능목록.json입니다.

현재 서비스의 로그인·카드결제·회원별 주문 권한·재고 처리·첨부 저장은 실제 서버 연동 완료가 아닙니다. 배송비 3,000원·취소 24시간·송장 8~30자리 등은 시연 기본값입니다. 노출순서는 견적 포함 기능이지만 현재 활성 화면에서 미구현입니다. 상세 에디터와 정책 설정 UI 등 추가 범위는 DEC-015에서 합의가 필요합니다.

문서 생성: 저장소 outputs/build_planning_v2_1.py를 번들 Python으로 실행합니다. 렌더 검토 이미지는 작업용 QA 폴더에서 별도 관리하며 전달 자료에 포함하지 않습니다.

## v2.1 수정 사항

관리자 → 예약관리시스템 / 커머스관리시스템 계층으로 수정했습니다. 송장 엑셀 업로드·양식 다운로드는 제외하고 직접 입력과 선택 주문 일괄 발송을 유지합니다. 목록 CSV 내려받기는 남아 있습니다. 화면 ID·기능 ID·테스트 ID·결정 항목 ID는 프로젝트 명명 규칙이며 업계 공통 표준 코드가 아닙니다.
